# Global Offshore Public Registry Hub

공개용 해외 법인·부동산·공시 공식기관 링크포털입니다.

## 구성
- `index.html`: 메인 웹페이지
- 별도 서버 없이 정적 호스팅 가능
- GitHub Pages / Cloudflare Pages / Netlify 등에 바로 배포 가능

## GitHub Pages 배포 방법
1. GitHub에서 새 Repository를 만듭니다.
2. 이 폴더의 `index.html`을 Repository 최상위에 업로드합니다.
3. Repository의 `Settings` → `Pages`로 이동합니다.
4. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, Folder는 `/ (root)`를 선택합니다.
6. 저장 후 생성된 GitHub Pages 주소로 접속합니다.

## 공개용 운영 원칙
- 개인정보, 사건번호, 조사대상명, 조사메모를 저장하지 않습니다.
- 각국 정부·법원·법인등기기관·토지등기기관·금융감독기관 등의 공식 링크를 우선 사용합니다.
- 각 사이트의 공개범위, 이용료, 로그인 조건은 변경될 수 있으므로 주기적으로 재검증해야 합니다.
